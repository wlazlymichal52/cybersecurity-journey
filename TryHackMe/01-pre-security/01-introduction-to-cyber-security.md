# Introduction to Cyber Security

W tym module zapoznałem się z podstawowymi zagadnieniami związanymi z cyberbezpieczeństwem oraz różnicami pomiędzy Offensive Security i Defensive Security.

## Offensive Security Intro

Offensive Security koncentruje się na identyfikowaniu i wykorzystywaniu podatności w systemach w celu sprawdzenia ich poziomu bezpieczeństwa.

W ramach ćwiczenia wykorzystałem narzędzie DirBuster do przeprowadzenia podstawowego rekonesansu aplikacji internetowej. Narzędzie pozwoliło na wykrycie ukrytych zasobów aplikacji, a następnie wykorzystanie znalezionej funkcjonalności w ramach przygotowanego scenariusza.

## Defensive Security Intro

Defensive Security koncentruje się na wykrywaniu zagrożeń, analizowaniu aktywności atakujących oraz stosowaniu mechanizmów mających na celu ochronę systemów.

W ramach ćwiczenia zapoznałem się z podstawowymi sposobami ochrony aplikacji internetowej przed automatycznym wykrywaniem jej zasobów. Przeanalizowałem m.in. ograniczanie liczby żądań, blokowanie adresów IP oraz stosowanie mechanizmów utrudniających prowadzenie tego typu ataków.

## Careers in Cyber

Cybersecurity obejmuje wiele specjalizacji, m.in. Offensive Security, Defensive Security, Security Operations, Digital Forensics oraz Incident Response.

W trakcie modułu zwróciłem uwagę na znaczenie praktycznych umiejętności oraz ciągłego rozwijania wiedzy w tej dziedzinie.

Na obecnym etapie nauki najbardziej interesuje mnie rozwój w kierunku Security Operations (SOC).
