# Introduction to Cyber Security

Rozpoczynam swoją naukę dziedziny Cyber Bezpieczeństwa, poprzez stronę 
tryhackme.com, która poprowadzi mnie poprzez pierwsze fundamentalne kwestie

## Offensive Security Intro

Offensive Security - to symulowanie akcji hakera, aby znaleźć słabość

Wykonałem zadanie, polegające na użyciu wirtualnej maszyny - czyli programu, który symuluje działanie systemu komputerowego. Polegało ono na tym, aby przy użyciu terminala, uruchomić narzędzie "dirbuster", które wykryło ukrytą podstronę banku, dzięki której byłem w stanie przypisać do swojego konta określoną kwotę pieniędzy.

## Defensive Security Intro

Defensive Security - wykrywanie hakerów i ich działań, oraz podejmowanie akcji, które mają ich powstrzymać

Wykonałem zadanie, polegające na użyciu wirtualnego programu, który poprzez swój ilustrowany wygląd miał w mocnym uproszczeniu wyjaśnić, na czym polega wykrycie potencjalnych ataków hakerskich i ich powstrzymanie. Na ten moment nie używałem żadnych komend, a zaznajomiłem się z wyżej wymienionym tematem wizualnie, przedstawiał on próby znalezienia podstron - podobnych do tej, której używałem w module Offensive Security. Sposób, w który poradziłem sobie z atakiem hakerskim, to zablokowanie jego adresu IP, wyznaczenie limitu tego, jak szybko podane podstrony mogą zostać wyszukane, oraz włączenie ogólnej ochrony przed tym atakiem.

## Careers in Cyber

W tym module dowiedziałem się, że Cyber Bezpieczeństwo to bardzo szybko rozwijająca się dziedzina, gdzie przede wszystkim potrzebne są praktyczne umiejętności. Narażone na atak hakerski są wszelkie pracówki typu szpitale, fabryki, sieci energetyczne itp. W Cyber Bezpieczeństwie jest wiele różnych ról, jakie może pełnić pracownik, do tego każda nowa i rozwijająca się technologia poszerza całą dziedzinę o kolejne potrzeby.
